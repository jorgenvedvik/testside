    Må jeg kunne kode for å lage en sånn side? +

    Nei. Det hjelper å forstå litt om hvordan HTML, CSS og JavaScript henger sammen, men du kan komme langt bare ved å beskrive hva du vil ha.

    Hva er forskjellen på GitHub og Vercel? +

    GitHub lagrer koden og historikken. Vercel henter koden derfra og gjør den om til en nettside med egen adresse.

    Koster det noe? +

    For en liten personlig side som denne holder gratisnivåene til både GitHub og Vercel lenge.

    Hvor kom designet fra? +

    Det er inspirert av rolige, redaksjonelle produktsider: kremfarget bakgrunn, stor serif med kursiv, avrundede kort og myke pastellfarger.
